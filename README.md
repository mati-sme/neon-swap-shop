# Neon Swap Shop

A cozy cyberpunk swap-shop game for phones (vanilla HTML/CSS/JS, no build step, no CDNs). You run a swap shop on a
neon space station: serve customers, haggle, spot fakes, dig in the junk dump and grow your shop.
Inspired by shopkeeper sims. All art is procedural pixel art; all sounds are synthesized. Kid-friendly: no violence.

## How to play
- **Move:** touch anywhere and drag (floating invisible joystick). Desktop: WASD / arrows or mouse drag.
- **Act:** walk near a station and tap the big round button (desktop: E / Space).
  - 🔓/🔔 Counter: open the shop, then call the next customer
  - 🏷️ Shelf: choose what is on display · 📦 Box: your items (♻ recycle for coins)
  - 🔧 Bench: ✨ polish (worth 1.5x) or x3 ➜ ⬆ merge into a better tier
  - 🚪 Junk Dump: limited digs, limited bag — tap 3 times per dig, find rare loot
  - 🛏️ Pod: sleep, pay the weekly fee, start a new day
- **Trade:** ✓ accept · ↔ haggle (stop the needle on green) · 🔍 inspect (compare with the handbook: ✅ real / 🚫 fake;
  fakes differ in logo, button count or stripe colour) · 🔎✨ appraise rare items (find 3 hidden marks) · ✗ no.
- Streaks multiply coins, every level gives a chest and a new decoration, the fee never ends the game.

## Run
Serve the folder with any static server, e.g. `python3 -m http.server`, and open it on a phone (installable PWA, works offline).
Debug: `?fast=1` runs game time 3x. `window.__game` exposes state for tests.

## Test
`node test/smoke.mjs` (needs Playwright + Chrome; set `PLAYWRIGHT_PATH` if playwright is not resolvable). Screenshots go to `test/shots/`.
Icons are generated by `python3 tools/make-icons.py`.
